🧠 Hybrid Ensemble Architecture

EmoSense AI uses a dynamic alpha-weighted soft voting pipeline that merges semantic representations (XGBoost) and deep contextual models (RoBERTa) to maximize classification accuracy while maintaining excellent processing speeds.

📄 Raw Text Input
Input text is passed parallelly to both the Semantic and Contextual pipelines.
▼
▼
▼
Branch 1: Semantic (XGBoost)
Extracts word/char TF-IDF n-grams + 10 normalized emotion feature dimensions from the NRC Emotion Lexicon. Standardized with a StandardScaler and classified via XGBoost.
Branch 2: Contextual (RoBERTa)
Tokenized text is evaluated using a custom fine-tuned RoBERTa-base sequence classifier, extracting deep lexical contextual and semantic signals.
▼
Dynamic Alpha Blending (Soft Voting)
Merges probability vectors from XGBoost and RoBERTa using a dynamic alpha (α) weight parameter. The final prediction distribution is calculated as: α * RoBERTa + (1 - α) * XGBoost.

📚 Training Dataset Details

The underlying models were trained on a high-quality, pre-processed emotional text dataset containing over 17,500 meticulously labeled records across 6 emotion classes.

Dataset Attribute Implementation Details
Total Size ~17,500 meticulously labeled text records.
Emotion Classes 6 distinct classes (Joy, Sadness, Anger, Fear, Surprise, Neutral).
Preprocessing Pipeline Removal of URLs, HTML tags, and special characters. Lowercasing and advanced tokenization to ensure clean inputs.
Feature Extraction TF-IDF vectors (words/characters) + 10-dimensional emotional vector generated using the NRC Emotion Lexicon.
Stratified Validation Deterministic (seed 42) stratified sampling ensures unbiased, balanced evaluation across all classes.
